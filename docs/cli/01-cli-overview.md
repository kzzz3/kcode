# KCode CLI

## Current commands

- `kcode init` - initialize a workspace
- `kcode config show` - print configuration system placeholder
- `kcode doctor` - validate runtime prerequisites

## Example

```bash
python -m apps.cli.src.kcode_cli init
python -m apps.cli.src.kcode_cli doctor
```
